Forkyard · the open-source Git client

A Git client that showswhat Git is doing.

Forkyard is a free Git GUI for Windows, Linux and macOS. Commit graph, line staging, a three-way merge tool and interactive rebase, all running on the git you already have installed. No account and no telemetry.

03 · Features

    
Everything you need for daily Git work.

    
From a first commit to a release with worktrees, submodules and signed tags.

    

      

        
History and graph

        
    
          
  • Commit graph with branch lanes, merge lines, ref labels and a WIP row
    • 
          
  • Search by message, SHA and author; file history and blame
    • 
          
  • Compare any two commits, or a commit with your working directory
    • 
          
  • Pin, hide or solo branches; smart branch visibility for large repos

Committing

        
    
          
  • Stage files, hunks or single lines, CRLF, Latin-1 and missing final newlines included

  • Side-by-side and inline diff with word-level highlighting and syntax colours
    • 
          
  • Built-in editor with Markdown preview

  • Undo for reset, rebase, discard and branch delete

04 · Privacy

    
Your repositories stay on your machine.

    
Forkyard has no backend and no account system. It talks to the remotes you push to and pull from and, if you connect them, to the GitHub or GitLab API. It sends nothing anywhere else.

    

      
OS keychain only
Tokens and passwords go to the Windows Credential Manager, macOS Keychain or Secret Service. They never reach the database, a log or the screen.

      
No telemetry
No usage statistics, no crash reports, no update pings to a Forkyard server, because there is none.

      
Locked until trusted
Repositories whose config or hooks would start a program stay read-only until you agree.

    

  






  

    

      
05 · How it works

      
Built on real Git.

      
A Rust core runs the git you already have installed. The interface only draws what Git reports.

    

    
    

      
Rust
A core that runs your own git, version 2.39 or newer.

      
Local
No account, no telemetry, no Forkyard server.

      
Keychain
Secrets go to the OS keychain, never to the database or a log.

      
Tauri 2
A native window on the system web view, with no bundled browser.
