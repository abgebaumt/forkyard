# Code of conduct

Forkyard follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment,
insults and personal attacks are not tolerated in issues, pull requests or any other project space.

If you experience or witness unacceptable behaviour, report it privately through
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or by contacting the maintainer via the GitHub profile [@abgebaumt](https://github.com/abgebaumt).
Reports are handled confidentially.
